# 工作板块 · 线框原型描述

做一个移动端个人考勤管理交互原型（自记录用途，非公司考勤系统）。员工可管理假期日历、按打卡模式打上下班卡、查看本月出勤统计；支持法定假日自动导入、日历点选覆盖、临时加班段与本地打卡提醒。使用模拟数据展示正常、迟到、早退、未到点锁定、补记等状态，让评审者点一遍即可理解完整流程和每一步反馈。

## 整体结构

底部导航三个 Tab：**打卡 → 工作 → 设置**，打卡为默认首位。线框风格（灰阶、虚线框、斜纹占位），底部弹层、圆钮等核心控件均可真实点击。

## 打卡页（Tab 首位）

- 顶部显示"今日 · 日期 · 星期"与当日班段摘要（如"早班 08:00–12:00 / 午班 13:00–17:30"）。
- **打卡圆钮**：内部两行文字——主文字「上班打卡 / 下班打卡」，下方小字显示所属段名与时段（如"早班 08:00–12:00"）。圆钮严格按顺序指向第一个未完成的待打卡项，不跳过：早班上班 → 早班下班 → 午班上班 → 午班下班。
  - 下班卡未到段结束时间时，圆钮呈灰色虚线锁定态，小字提示"XX:XX 后可打"，到点自动解锁。
  - 全部打完后圆钮显示"今日已打完"的锁定态。
- **今日记录（待办式）**：按段分组的待办列表，每条为「勾选框 + 上班/下班 + 实际时间 + 状态标签」。点圆钮打卡相当于快速勾选；直接点待办条目也可勾选（记录勾选时刻）或再次点击取消（恢复"待打"）。状态自动判定：
  - 上班卡：早于/等于上班时间 → 正常；晚于 → 迟到（红标）。
  - 下班卡：晚于/等于下班时间 → 正常；早于 → 早退（黄标）。
  - 忘打卡：事后在记录里直接勾选补记，标「补记」，无审批流程。
- **临时加班段**：「＋ 临时加班段」按钮可连续添加多个，每段一行内联布局：段名 + 起止时间选择器（紧跟段名后，可改任意时间并同步更新打卡判定）+ 删除按钮，下面是该段的上班/下班待办。加班段仅记录当天，不影响默认排班。
- **本月出勤**条：应勤 / 实勤 / 迟到 / 漏卡数字。
- 页面右上可切换**打卡模式**：每段一对（早/午/晚各打上下班）或整日一对（只打上班+下班），切换后待办列表与圆钮即时联动。

## 工作页（假期日历）

- **月历视图**：可翻月，周一起始。每日按类型着色并带角标——法定假日（红）、调休上班（橙）、自定义假（蓝）、请假（紫）、周末休（灰）、今天（虚线描边）。
- **点选日期**：弹出底部动作面板，显示该日当前状态与时段，可操作：标为自定义假 / 标为请假 / 标为上班 / 恢复默认；下方可编辑当日上下班时段（改时间、加段）。标记后月历颜色即时联动。
- **快捷设置**：单休（周日休）/ 双休 / 大小周 一键切换，从今天起生效；已手动标注的日期保留覆盖。
- 标记优先级：用户点选覆盖 > 法定假日/调休数据 > 星期规则。
- **下次假日**卡片：显示最近假日名称、日期范围与倒计时。

## 设置页

- **打卡模式**：每段一对 / 整日一对 单选。
- **默认上下班时段**：多段增删改（如 08:00–12:00、13:00–17:30），每段独立打卡与提醒。稳定的多段排班在此配置，临时变动用打卡页的加班段。
- **打卡提醒**：总开关、提前提醒分钟数（步进器）、到点提醒开关、未打完兜底提醒（如 20:00）开关。
- **迟到判定宽限**分钟数（默认 5）。
- **法定假日数据**：显示已更新年份，可手动刷新（在线 API 拉取，失败回退星期规则）。

## 模拟数据

日历预置 2026 年 9–10 月示例：国庆/中秋法定假、9/26 与 10/10 调休上班、9/30 年假；今日预置"早班上班 07:56 正常"一条已完成记录，其余待打。时钟实时走字，评审者可在任意时间点验证迟到/早退/锁定判定。

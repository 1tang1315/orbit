## 4. 设计语言

| 项 | 值 |
| --- | --- |
| 背景 | Notion 暖米底 `#F7F6F3` |
| 主色 / L1 原料卡 | 紫 `#9B5DE5` |
| L2 主题卡 | 橙 `#F26430` |
| L3 项目卡 | 绿 `#0F9D58` |
| 正文 | 深灰 `#37352F`，次级 `#9B988F`，描边 `#E8E6DF` |
| 字体 | 中文 Noto Sans SC，英文/数字 Inter |

移动端规格：屏宽 390；内容区左右 padding 16；卡片 radius 14、白底描边；底部胶囊 Tab 栏高 62、radius 36、激活态实心紫。

## 5. 状态与来源标签（正交两套语言）

- 来源标签：紫 = 需求，红 = Bug 快轨。
- 状态色：橙 = 待确认，绿 = 完成。

两套语言不混用：来源回答「从哪来」，状态回答「到哪步」。
